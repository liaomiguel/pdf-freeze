# Impeccable Design System & Product Rules

This skill enforces high-end, serious design standards for web applications, avoiding generic "AI-generated" visual patterns ("AI slop").

## Core Principles

1. **Serious & Enterprise Aesthetics ("Product Mode")**
   - Use sober, professional color palettes: slate, zinc, deep navy, cool grays, with precise accent colors (corporate blue, cyan, or emerald).
   - Avoid cheap bright purple-to-pink gradients, glowing neon boxes, and unnecessary decorative emojis.
   - Enforce strong structural alignment, visual weight, crisp borders, and purposeful whitespace.

2. **Typography & Layout**
   - High-contrast, clean typography hierarchy (Inter, system sans-serif font stack).
   - Clear semantic headings (`h1`, `h2`, `h3`) with explicit font weights and line heights.
   - Consistent container max-widths (e.g., 768px for focused tools, 1140px for dashboards).

3. **High Affordance & Interactive Feedback**
   - Drag and drop zones must have distinct hover, focus, dragover, and file-selected visual states.
   - Buttons must look actionable, with clear disabled states and active feedback.
   - Clear progress meters with percentage text, item counters, and error states.

4. **Trust & Security Architecture**
   - Display trust signals cleanly: badges for 100% Client-Side Processing, Zero Server Data Storage, and SHA/Privacy guarantees.
   - Provide technical clarity without overwhelming clutter.
