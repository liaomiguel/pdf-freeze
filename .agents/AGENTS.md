# Project Rules & Design Guidelines (Impeccable)

- **Design Standard**: Follow the Impeccable design system (`.agents/skills/impeccable/SKILL.md`).
- **Visual Style**: Serious, enterprise-ready, high privacy trust tool. Avoid generic playful gradients, overused emojis, and unstyled form controls.
- **Color Palette**: Dark Slate (`#0f172a`, `#1e293b`), Steel Border (`#334155`), Crisp Neutral Text (`#f8fafc`, `#94a3b8`), Primary Action Slate Blue (`#2563eb`), Success Emerald (`#059669`).
- **Privacy & Security Focus**: Highlight 100% Client-Side browser processing prominently with professional UI badges and technical trust cards.
